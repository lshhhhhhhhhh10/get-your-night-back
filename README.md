# Get Your Night Back

从夜间取回设备的生活经验出发，学习观察地板、门轴与父母状态的低多边形 3D 浏览器游戏。设计：Daniel；实现协作：Codex。

## 在线游玩

- 项目首页：https://lshhhhhhhhhh10.github.io/get-your-night-back/
- 直接游戏：https://lshhhhhhhhhh10.github.io/get-your-night-back/game.html
- 公开仓库：https://github.com/lshhhhhhhhhh10/get-your-night-back

## 运行

静态成品已放在仓库根目录，无需安装依赖即可通过 GitHub Pages 游玩。

本地预览：在仓库根目录运行 `python3 -m http.server 4173`，打开 `http://localhost:4173/`。不要直接双击 HTML；游戏使用 JavaScript 模块。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 看向四周 | WASD 或方向键连续移动；第一人称点击画面后用鼠标转头 |
| 第一人称 / 全景 | 点击左上角小地图或按 M；Tab 释放鼠标 |
| 松动地板落脚 / 接住花瓶 | 指针进入亮区时按空格 |
| 搜索 | 靠近客厅柜子按 E，约 6 秒完成；Esc 可取消 |
| 开门 | 靠近按 E 进入，再按住 E 推门 |
| 调门速 | 左右键、滚轮或屏幕滑块 |
| 躲藏 / 离开掩体 | 靠近高背椅、沙发、高柜按 C |
| 停下动作 / 暂停 | Esc；离开标签页自动暂停 |
| 设置 | 主菜单或暂停菜单进入；总音量、环境音、提示音、鼠标灵敏度和镜头起伏 |

主菜单 **START** 首次进入第一关；之后恢复同一浏览器中保存的位置、门、搜索、设备和父母状态。通关后继续下一关，失败后重试当前关。**挑战关卡** 展示三张地图，选中后点击开始，会从该关重新开始。进度自动保存在当前浏览器，清除网站数据后会丢失；不跨设备同步。

新关卡先展示全景，第一次移动自动切为第一人称。用小地图或 M 手动切换后，保留所选视角。普通地板连续行走；危险地板仍会暂停并要求落脚判断。

设备拿到后还须回到卧室。一次响声不直接失败；父母在无遮挡近距离视线中持续识别 1.65 秒才失败。移动中可取消行动、撤退，失败后可读关键因果链并立即重试。

## 三组挑战

1. **第一声吱呀**：固定短路线、一块松动地板、一扇门、一个藏点；父母默认熟睡，过大噪声仍可能引起检查。
2. **今晚走哪边**：开放第二条路线，增加旧门、易响地板与三个藏点。
3. **脚步近了**：相同小住宅加入有预警的起夜、家具遮挡、一次擦近花瓶才触发的接物件事件。

三个挑战合计约五分钟是设计目标，不是已经测量的人类玩家平均时长。没有体力条、喝水量、分数或强制倒计时。

## 依赖：Track C

| 依赖 | 固定版本 | 许可 | 用途 |
| --- | --- | --- | --- |
| Three.js | 0.180.0 | MIT | 3D 场景、角色、相机与灯光 |
| Vite | 6.3.6 | MIT | 开发时将源码及依赖构建为静态模块 |

依赖版本保存在 `source/package.json`，完整依赖锁定在 `source/package-lock.json`。许可证副本位于 `assets/vendor/`。住宅、家具和父母由项目几何代码生成；玩家使用学生提供的 PEAK 角色附件，经 Blender 修复贴图和添加骨骼后导出为本地 GLB，来源见 `assets/models/README.md`。环境音与动作提示由 Web Audio 合成，字体采用系统字体；无 CDN、外部字体、付费 API 或运行时远程服务。

修改代码后：

```sh
cd source
npm ci
npm test
npm run build
```

构建输入：`source/main.js`、`source/engine.js` 与 `source/persistence.js`。构建输出：`assets/build/game.js`。`base: './'` 保证仓库子路径可用。无需把 `node_modules` 上传到 GitHub。

## 主要变量和规则

| 类别 | 变量 | 含义 |
| --- | --- | --- |
| 环境 | `PRESETS`, `wall`, `COVERS` | 三关地板、门速适宜区间、藏点与起夜设置；墙与掩体 |
| 环境 | `playerBlocked` | 家具、墙、柜子等实际行走障碍 |
| 玩家 | `player.x/z`, `heading`, `velocity` | 连续位置、朝向与速度，逐帧处理移动与碰撞 |
| 视角 / 存储 | `view`, `settings`, `SAVE_KEY` | 第一人称/全景、音量与灵敏度、本机进度 |
| 玩家 | `pointer`, `speed`, `hidden` | 落脚/接物件时机、门速、蹲下状态 |
| 系统 | `noise`, `noiseAt`, `quiet` | 最近声响、声源位置与安静时间 |
| 系统 | `parent.a` | 0–100 警觉，30 警觉、60 准备检查 |
| 系统 | `parent.state/route/recognition` | 熟睡/警觉/预警/检查/回房、寻路结果、识别累计 |
| 系统 | `hasDevice`, `spots`, `vase`, `status` | 设备、搜索、物件状态与胜负 |

听到的声音：动作噪声 × 遮挡系数 ÷ 距离衰减。无新刺激 3 秒后警觉每秒下降 2.1。起身前保留 5 秒声音预警。父母移动采用可达网格寻路，无遮挡、足够近、朝向合适时才累计识别。

重要的警觉数值用于内部计算；玩家读取鼾声、床响、脚步、灯光和字幕。父母模型不会隔墙显示，藏点不直接显示设备答案。坐下的姿态不会提供魔法隐身：家具要位于父母和玩家之间才有效。

## 检查与限制

规则检查：`npm test`。浏览器验证包括真实按键打开门、落脚、搜索、带设备返程、家具躲藏、持续视线失败、重试和暂停。详见开发日志与过程页。

桌面键盘是主要交互方式；窄屏提供触屏方向按钮和情境交互，但不作为完整移动端体验承诺。WebGL 需要浏览器硬件加速。学生已完成初版试玩并指出菜单、卡顿、模型和视角问题；v0.2.0 按这些反馈重构。新版仍需学生体验，实际人类时长与学习效果尚未测量。
