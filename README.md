# Get Your Night Back

从夜间取回设备的生活经验出发，学习观察地板、门轴与父母状态的低多边形 3D 浏览器游戏。设计：Daniel；实现协作：Codex。

## 在线游玩

- 项目首页：https://lshhhhhhhhhh10.github.io/get-your-night-back/
- 直接游戏：https://lshhhhhhhhhh10.github.io/get-your-night-back/game.html
- 公开仓库：https://github.com/lshhhhhhhhhh10/get-your-night-back

## 运行

静态成品已放在仓库根目录，无需安装依赖即可通过 GitHub Pages 游玩。

本地预览：在仓库根目录运行 `python3 -m http.server 4173`，打开 `http://localhost:4173/`。不要直接双击 HTML；游戏使用 JavaScript 模块。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 看向四周 | WASD 或方向键连续移动；第一人称点击画面后用鼠标转头 |
| 第一人称 / 全景 | 点击左上角小地图或按 M；Tab 释放鼠标 |
| 松动地板落脚 / 特写中接住物件 | 指针进入亮区时按空格 |
| 搜索 | 靠近各房间的候选柜子按 E，约 6 秒完成；Esc 可取消 |
| 开门 | 靠近按 E 进入，再按住 E 推门 |
| 调门速 | 左右键、滚轮或屏幕滑块 |
| 蹲行 / 站起 | C 切换；蹲下可移动和交互，声音更轻，需借家具挡住视线 |
| 停下动作 / 暂停 | Esc；离开标签页自动暂停 |
| 设置 | 主菜单或暂停菜单进入；总音量、背景音乐、环境音、提示音、鼠标灵敏度和镜头起伏 |

主菜单 **开始夜探 / START** 首次进入第一关；之后恢复同一浏览器中保存的位置、门、搜索、设备和父母状态。通关后继续下一关，失败后重试当前关。**挑战关卡** 展示三张地图，选中后点击开始，会从该关重新开始。进度自动保存在当前浏览器，清除网站数据后会丢失；不跨设备同步。v0.2 / v0.3 旧地图存档升级为 v4 时保留所在关卡，从该关开局；这是为避免旧设备、藏点和位置状态与新户型冲突。

新关卡先展示全景，第一次移动自动切为第一人称。用小地图或 M 手动切换后，保留所选视角。小地图仅显示玩家周围约四格半径，不显示全屋，也不标出设备或父母。普通地板连续行走；松动地板不再使用特殊颜色或地图标记，踩上时有受力声和落脚判断，亮区缩为第一关 22%、后两关 16%。

设备拿到后还须回到卧室。一次响声不直接失败；父母在无遮挡近距离视线中持续识别 0.25 秒才失败。移动中可取消行动、撤退，失败后可读关键因果链并立即重试。

家具布局统一在 `source/layout.js`，模型细节位于 `source/furniture.js`。调整位置、尺寸或朝向时，模型、身体碰撞、家长寻路与小地图同步改变。天花板下沿和完整墙顶均为 2.6，门洞净高约 2.2；全景显示剖面，第一人称恢复完整室内空间。

## 三组挑战

1. **第一声吱呀**：客厅连通东侧书房，两个候选藏点；父母默认熟睡，噪声累积仍会引起检查。
2. **今晚走哪边**：开放餐厅、储物间、洗衣间与后走廊，五个候选藏点，可以绕行或穿过旧门。
3. **脚步近了**：扩建住宅中加入有预警的起夜巡视、家具遮挡与花瓶事件。父母可以巡至东侧房间和后走廊。

原先约五分钟为初版目标；最新学生反馈要求更大的探索空间，本版不再以五分钟限制地图。实际人类时长尚未测量。没有体力条、喝水量、分数或强制倒计时。

## 表现评价与场景意外

通关后显示四项评分与理由，不以用时扣分。未通关只显示练习记录，不授予通关等级。

| 标准 | 分值 | 依据 |
| --- | --- | --- |
| 任务完成 | 40 | 设备安全带回卧室 |
| 声音控制 | 25 | `max(0, 1 - noiseBurden / 160) × 25`；每次噪声大于 10 时累计超出部分 |
| 动作判断 | 25 | 成功落脚、接物及安静推门比例；推门按实际操作时长统计，合为一个动作权重 |
| 避开视线 | 10 | 每次进入家长有效视线扣 5，最低 0 |

各项四舍五入。S ≥ 90，A ≥ 75，B ≥ 60，否则 C。探索、等待和没有触发随机事件不扣分；评分仅在结算显示。旧 v4 续玩缺少过去行为时，注明从更新后开始统计，不伪造原表现。

翻找餐边柜、书房抽屉和储物柜约 2.2 秒后，可能发生叉子、笔筒或铁盒滑落，概率分别 65%、45%、50%。`seed` 与 `incidentUsed` 保存在本局进度中，重复取消或刷新不会重抽，每种事件最多一次。花瓶仍由固定地点触发。

近景先给 0.45 秒准备，再用同一个空格键在亮区内接住物件，整个窗口约 3.2 秒。成功后继续原搜索；失手播放对应声响。Esc 放弃接物，结果阶段再按 Esc 可以停止继续搜索。暂停或刷新保留事件时机。特写中世界以 12% 速度运行，并暂缓识别以避免无法移动时判负；结束后恢复原 0.25 秒识别。`realTime` 记录实际游玩时间，`time` 驱动世界和家长。

## 声音

原创稀疏拨弦与钟琴夜曲循环播放；父母起身时音乐降低，让脚步更突出。松动木板有受力轻响、成功落脚短吱声与失误落脚强吱声。木地板、瓷砖、蹲行、父母脚步、鼾声、床响、不同推门速度、门锁和翻找都有独立反馈。门声使用真实把手、门轴、关门和门锁录音切片，轻推与过慢摩擦采用不同音量及速率。声源根据距离、墙体和视线朝向改变音量与左右方向；声音提示保留字幕。浏览器须在点击开始或设置后才允许播放。

## 主要变量和规则

| 类别 | 变量 | 含义 |
| --- | --- | --- |
| 环境 | `PRESETS`, `wall`, `furnitureFor` | 三关地板、门速适宜区间、藏点与起夜设置；墙与掩体 |
| 环境 | `canStand`, `circleHits`, `doorShape` | 圆形身体与实际家具、墙体、旋转门板碰撞 |
| 玩家 | `player.x/z`, `heading`, `velocity` | 连续位置、朝向与速度，逐帧处理移动与碰撞 |
| 视角 / 存储 | `view`, `settings`, `SAVE_KEY` | 第一人称/全景、音量与灵敏度、本机进度 |
| 玩家 | `pointer`, `speed`, `hidden` | 落脚/接物件时机、门速、蹲行状态 |
| 系统 | `noise`, `noiseAt`, `quiet` | 最近声响、声源位置与安静时间 |
| 系统 | `parent.a` | 0–100 警觉，30 警觉、60 准备检查 |
| 系统 | `parent.state/phase/intent/route/recognition` | 熟睡/警觉/预警/检查/回房，走动/观察/推门阶段、声源调查意图、路线与识别累计 |
| 系统 | `hasDevice`, `spots`, `vase`, `status` | 设备、搜索、物件状态与胜负 |

听到的声音：动作噪声 × 遮挡系数 ÷ 距离衰减。无新刺激 3 秒后警觉每秒下降 2.1。起身前保留 5 秒声音预警。父母移动采用半格寻路，与家具碰撞共用尺寸。定时巡视按轮次经过三个地点，每处观察 2.6 秒；听到的声音达到 6 才提供新调查目标，每次最多每 1.2 秒重定向，声源附近观察 3.5 秒。家长先推门再通过，完整开门约 1.4 秒，并绕开打开的门板；最后实际走回床边。无遮挡、足够近、朝向合适时才累计识别。

重要的警觉数值用于内部计算；玩家读取鼾声、床响、脚步、灯光和字幕。父母模型不会隔墙显示，藏点不直接显示设备答案。坐下的姿态不会提供魔法隐身：家具要位于父母和玩家之间才有效。第一人称画面中的家长由实际墙体与家具深度遮挡，不再因脚下的二维射线被整体隐藏；矮家具后露出的头部仍可见。

## 检查与限制

规则检查：`npm test`。浏览器验证包括真实按键打开门、落脚、搜索、带设备返程、家具躲藏、持续视线失败、重试和暂停。详见开发日志与过程页。

桌面键盘是主要交互方式；窄屏提供触屏方向按钮和情境交互，但不作为完整移动端体验承诺。WebGL 需要浏览器硬件加速。学生已完成初版试玩并指出菜单、卡顿、模型和视角问题；v0.2.0 按这些反馈重构；v0.3.0 再按学生要求扩大探索并加强声音和潜行难度。新版仍需学生体验，实际人类时长与学习效果尚未测量。
