# Get Your Night Back

从夜间取回设备的生活经验出发，学习观察地板、门轴与父母状态的低多边形 3D 浏览器游戏。设计：Daniel；实现协作：Codex。

## 协作与文档入口

新任务先读 [AGENTS.md](AGENTS.md) → [PROJECT_STATUS.md](PROJECT_STATUS.md) → [简报当前规则与相关设计](brief.md#current-rules)；需要溯源时再查 [开发日志](development-log/agent-development-log.md)。

每轮自动维护当前状态；已确认玩法同步简报，旧规则标明替代关系。长期规则不堆版本日志，AI 实施选择不冒充用户确认，学生反思由学生填写。[原始导出稿](development-log/brief-original.md) 原样存档，工作简报与历史记录继续保留。具体维护方式见 AGENTS。

本次发布版本为 **v0.14.3**：远近镜头共用精细家具与物件，接住后送回原处，手臂缩短并自然弯肘；保留门框撞击与走路无震动修订。发布核验进度见 [项目状态](PROJECT_STATUS.md)。

主菜单 **开始夜探 / START** 首次进入第一关；之后恢复同一浏览器中保存的位置、门、搜索、设备和父母状态。通关后继续下一关，失败后重试当前关。**挑战关卡** 展示三张地图，选中后点击开始，会从该关重新开始。进度自动保存在当前浏览器，清除网站数据后会丢失；不跨设备同步。v0.2 / v0.3 旧地图存档升级为 v4 时保留所在关卡，从该关开局；这是为避免旧设备、藏点和位置状态与新户型冲突。

新关卡先展示全景，第一次移动自动切为第一人称。用小地图或 M 手动切换后，保留所选视角。小地图仅显示玩家周围约 4 格半径，不显示全屋，也不标出设备或父母。普通地板连续行走；松动地板不再使用特殊颜色或地图标记，踩上时有受力声和落脚判断，亮区缩为第一关 22%、后两关 16%。

设备拿到后还须回到卧室。一次响声不直接失败；父母在无遮挡近距离视线中持续识别 0.25 秒才失败。移动中可取消行动、撤退，失败后可读关键因果链并立即重试。

家具布局统一在 `source/layout.js`，模型细节位于 `source/furniture.js`。调整位置、尺寸或朝向时，模型、身体碰撞、家长寻路与小地图同步改变。天花板下沿和完整墙顶均为 2.6，门洞净高约 2.2；全景显示剖面，第一人称恢复完整室内空间。

## 三组挑战

1. **第一声吱呀**：客厅连通东侧书房，两个候选藏点；父母默认熟睡，噪声累积仍会引起检查。
2. **今晚走哪边**：开放餐厅、储物间、洗衣间与后走廊，五个候选藏点，可以绕行或穿过旧门。
3. **脚步近了**：扩建住宅中加入有预警的起夜巡视、家具遮挡与花瓶事件。父母可以巡至东侧房间和后走廊。

原先约五分钟为初版目标；最新学生反馈要求更大的探索空间，本版不再以五分钟限制地图。实际人类时长尚未测量。没有体力条、喝水量或全局竞速倒计时；完成后有表现评分。

## 表现评价与场景意外

通关后显示四项评分与理由，不以用时扣分。未通关只显示练习记录，不授予通关等级。

| 标准 | 分值 | 依据 |
| --- | --- | --- |
| 任务完成 | 40 | 设备安全带回卧室 |
| 声音控制 | 25 | `max(0, 1 - noiseBurden / 160) × 25`；每次噪声大于 10 时累计超出部分 |
| 动作判断 | 25 | 成功落脚、接物及安静开合门比例；开合门按实际操作时长统计，合为一个动作权重 |
| 避开视线 | 10 | 每次进入家长有效视线扣 5，最低 0 |

各项四舍五入。S ≥ 90，A ≥ 75，B ≥ 60，否则 C。探索、等待和没有触发随机事件不扣分；评分仅在结算显示。旧 v4 续玩缺少过去行为时，注明从更新后开始统计，不伪造原表现。

翻找餐边柜、书房抽屉和储物柜约 2.2 秒后，可能发生叉子、笔筒或铁盒滑落，概率分别 65%、45%、50%。`seed` 与 `incidentUsed` 保存在本局进度中，重复取消或刷新不会重抽，每种事件最多一次。花瓶仍由固定地点触发。

新救场依据手的位置、物件轨迹与支撑方式：花瓶要双手托住、扶正，再慢慢放回；铁盒要右手托底、左手压盖；叉子托住后用左手袖口止响；三枝铅笔分路滚动，用手掌逐枝拦下。只拦下部分铅笔时，按剩余数量减轻落地噪声。键鼠为 A / D 移手、Q / E 左右手、S 送回原处；手柄为左摇杆左右移手、L2 / R2 支撑、左摇杆向下推进归位。空格只用于松动地板。

救场最长 10 秒，失去支撑或物件越过桌沿时会结束，没有统一指针或正确区间。Esc 放弃，结果阶段再按 Esc 可停止自动继续搜索。暂停和刷新保存物件位置、阶段与搜索进度，释放物理输入，续玩给 0.65 秒重新接手。特写沿用世界 12% 速度和暂缓识别，结束恢复原 0.25 秒识别。旧 v4 存档中已经开始的指针接物可按原方法结束。

## 声音

原创稀疏拨弦与钟琴夜曲循环播放，起身和开合门时音乐降低。松动木板有受力轻响、成功短吱声和失误强吱声。木地板、瓷砖、地毯使用 12 个网络实录切片交替播放，玩家与家长按实际脚下材质选音；两块地毯的渲染和声学边界共用定义。门声使用真实把手、门轴和门锁录音，连续咯吱随施力改变，松手收声。

HRTF 随转头改变方位，距离改变音量和高频细节，隔墙或关门后声音更闷、更轻。短时字幕描述刚响起的方向和大致远近，不持续显示角色坐标。它是游戏声学近似，没有完整室内反射模拟。浏览器须在点击开始或设置后才允许播放；来源及加工方法见 [音频来源](assets/audio/README.md)。

## 主要变量和规则

| 类别 | 变量 | 含义 |
| --- | --- | --- |
| 环境 | `PRESETS`, `wall`, `furnitureFor` | 三关地板、藏点与起夜设置；墙与掩体 |
| 环境 | `canStand`, `circleHits`, `doorShape` | 圆形身体与实际家具、墙体、旋转门板碰撞 |
| 玩家 | `player.x/z`, `heading`, `velocity` | 连续位置、朝向与速度，逐帧处理移动与碰撞 |
| 视角 / 存储 | `view`, `settings`, `SAVE_KEY` | 第一/第三人称近景与全景、音量与灵敏度、本机进度 |
| 玩家 | `pointer`, `hidden`, `mode.drive` | 落脚时机、蹲行、临时施力/摩擦/转速 |
| 系统 | `noise`, `noiseAt`, `quiet` | 最近声响、声源位置与安静时间 |
| 系统 | `parent.a` | 0–100 警觉，30 警觉、60 准备检查 |
| 系统 | `parent.state/phase/intent/route/recognition` | 熟睡/警觉/预警/检查/回房，走动/观察/推门阶段、声源调查意图、路线与识别累计 |
| 系统 | `hasDevice`, `spots`, `vase`, `status` | 设备、搜索、物件状态与胜负 |

听到的声音：动作噪声 × 环境掩护系数 × 遮挡系数 ÷ 距离衰减。无新刺激 3 秒后警觉每秒下降 2.1。起身前保留 5 秒声音预警。父母移动采用半格寻路，与家具碰撞共用尺寸。定时巡视按轮次经过三个地点，每处观察 2.6 秒；听到的声音达到 6 才提供新调查目标，每次最多每 1.2 秒重定向，声源附近观察 3.5 秒。家长先推门再通过，完整开门约 1.4 秒，并绕开打开的门板；最后实际走回床边。无遮挡、足够近、朝向合适时才累计识别。

重要的警觉数值用于内部计算；玩家读取鼾声、床响、脚步、灯光和字幕。父母模型不会隔墙显示，藏点不直接显示设备答案。坐下的姿态不会提供魔法隐身：家具要位于父母和玩家之间才有效。第一人称画面中的家长由实际墙体与家具深度遮挡，不再因脚下的二维射线被整体隐藏；矮家具后露出的头部仍可见。

## PS5 手柄

使用支持数据传输的 USB 线将 DualSense 连接电脑，打开在线游戏页面并按一下 ×。页面显示“手柄已连接”后，松开再按 × 开始／续玩。若页面没有焦点，先点击页面一次；若浏览器限制声音，点击“开启声音”即可。无需安装手柄插件。

| 操作 | DualSense 按键 |
| --- | --- |
| 移动 / 转头 | 左摇杆 / 右摇杆 |
| 松动地板落脚 | × |
| 救场移手 / 托住 | 左摇杆左右 / L2 左手、R2 右手；按现场提示操作 |
| 放回花瓶 / 铁盒 | 保持双扳机支撑，左摇杆向下 |
| 挠痒痒 | □ 开始，轻压 R2 ＋ 右摇杆左右轻挠 |
| 启动道具 / 来电静音 | □ 交互；停下按住 1.2 秒静音 |
| 安抚猫 / 丢玩具球 | □ 安抚 / R2 投球 |
| 机械开锁 | □ 进入；左摇杆换针、R2 顶起后松开；腰形弹子卡肩时 L2 卸力 |
| 搜索、抓住门把 | □；进入开门后改用 R2 施力 |
| 开合门 | □ 抓住门把；轻压 R2 施力，松开停止；L1 换开合方向 |
| 蹲下、站起 / 取消当前动作 | ○ |
| 全景与第一人称切换 | △ |
| 暂停 / 继续 | Options |
| 菜单选择、确认、返回 | 方向键或左摇杆、×、○ |
| 设置滑块调整 | 上下选择，左右调整 |

轻推左摇杆慢走，推满恢复原最高速度；蹲行仍有较低速度与噪声。右摇杆小幅输入较细，按时间推进转头。设置独立保存 `gamepadSensitivity`（默认 1，0.3–2）与 `stickDeadzone`（默认 0.16，0.05–0.35）。键盘、鼠标仍可随时使用，提示随输入方式切换。

`source/gamepad.js` 负责径向死区、按键边沿、持有手柄与菜单重复；`source/main.js` 负责菜单和游戏动作分发。只使用 `mapping === "standard"` 的设备，不推断原始布局。拔插、失焦和切换菜单时清除遗留输入，松开后才能继续。存档结构不变，不保存物理按键状态。

浏览器依据：[Gamepad API 与首次识别](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API)、[Web Audio 用户交互限制](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)。通过 Chrome 模拟手柄进行自动检查，尚未实测实体 DualSense USB。v0.13 新增 USB 自适应扳机，连接步骤与限制见本文末尾及 [触觉说明](docs/controller-feedback.md)。


## 皮肤衣柜

主菜单 → 皮肤衣柜 → 选择“我自己”或“家长” → 选择外观 → 旋转预览 → 穿上这套。提供奶龙、奶蛙、奶鼠、围巾、螃蟹、厨师、纸箱、抱枕和睡帽九套，全部直接可用。鼠标拖动或转身按钮旋转；手柄方向键选择、× 确认、○ 返回，右摇杆旋转预览。

可分别更换玩家与当前家长角色。外观不改变速度、声音、碰撞、识别和评分，家长换装不增加巡查人数。选择卡只预览，确认后更新角色；刷新、续玩及换关保留外观，关卡进度不会被覆盖。存储不可用时当次仍可穿上，并显示不能保存的提示。

- `source/skins.js`：九套目录、稳定 ID；`night-back:skin:v1` 和 `night-back:parent-skin:v1` 分别保存。
- `source/skin-model.js`：模型克隆、改装配件和独立材质；共享模型不会被其他皮肤污染。
- `source/wardrobe.js`：三维预览、旋转、确认、载入失败重试和快速选择保护。
- `assets/models/peak-character-{1,2}.glb`：附件新增螃蟹与厨师模型；原第三角色继续共用。
- `assets/skins/`：从运行时实际模型截取的九张缩略图。

## 掩护与返程来电（v0.8 起，当前保留）

1. **观察柜锁**：当前直接操作机械结构，不再找文字线索。目标柜子附近可见充电器微光；不在小地图公开答案。开锁详情见本文“机械开锁与掉落动画”。
2. **借声音通过**：家长熟睡时每约 6 秒发出一次鼾声，其中开始后 0.1–1.6 秒可以掩护行动。洗衣机每 18 秒在第 7–13 秒脱水，约 7.5 场景单位内可借声；三关的洗衣间均有实际洗衣机。右上角显示当前掩护。有效时动作噪声降至 28% / 30%，进入松动木板直接连续通过并计为成功落脚。掩护不会阻断家长视线。
3. **把家长引向别处**：客厅收音机、走廊玩具鸭，以及后两关后廊收音机，都可用 E / □ 定时启动。每个道具每夜一次；2.5 秒后响起，间隔 1.6 秒发声，共四次。家长依照原有起身预警、寻路、调查和回房规则追查道具所在位置；玩家可以离开。故意启动道具不计作声音失误，实际被看见仍按原规则处理。
4. **手机并不安静**：找到设备后有 6 秒振动预警。停下（可保持蹲姿）新按住 E / □ 1.2 秒静音；移动或松手清空进度。错过预警会响铃，每 2.4 秒一次、最多三次，每次产生 38 基础噪声，受环境掩护和父母听觉规则影响。响铃中仍能静音，不会仅因来电直接判负。特写与暂停不消耗来电预警。

`source/night-tools.js` 共用道具位置、环境周期和状态；`source/night-props.js` 生成收音机与玩具鸭；道具和手机状态与进度一同保存。旧 `night.clues` 字段仅用于兼容存档，不再显示或参与开锁。刷新保留预警剩余时间，但要求重新按住；更新前已经拿到设备的旧存档不会突然补加来电。声音为本项目 Web Audio 合成，未新增依赖。


## 家里的猫（v0.9.0）

三关都有一只橘猫，从客厅走廊出现。看见附近的玩家后跟随，玩家停下时蹭腿、轻摆尾巴；普通猫叫和呼噜营造生活感，不会单独惊醒家长。猫绕开家具和关闭的门，不占用玩家碰撞空间，可以直接绕开。

- **安抚**：靠近按 E / □，猫坐下呼噜，安静约 18 秒。门、柜子等必要交互优先；附近有其他可操作物件时，也可点击猫咪面板的“安抚”。
- **玩具引开**：Q / R2 将软球丢向面前约 2.5 格的可达空地；正前方不通时尝试侧面安全落点，完全无落点则不投。猫追到后玩约 12 秒，投球冷却 14 秒。用完可以继续投，不增加货币或物品栏。
- **扑花瓶**：猫和玩家都接近花瓶时，它可能走到桌边、压低身子，给出 3.5 秒蓄势预警。安抚、投球或退离花瓶区域均可打断；当前正在开门、翻找时不消耗蓄势时间。每夜最多一次真正起跳。
- **来不及阻止**：猫扑向桌沿，复用原有慢动作接花瓶操作。接住后继续探索，落地声音从花瓶的实际位置影响家长调查及表现评分，不直接判负。猫的动作和音效不会额外改变视线识别规则。

旧进度会安全补上默认猫；新进度保存猫的位置、状态、安抚剩余时间、玩具及一次性事件标记。暂停冻结猫的行为，恢复会按实际门状态重新寻路。三关现在都显示原有花瓶，第三关原有碰花瓶入口仍保留，两种原因不会重复触发同一个花瓶。

`source/cat.js` 管理跟随、蹭腿、安抚、追球、蓄势及起跳；v0.9 的 `source/cat-model.js` 是本项目原创程序几何橘猫，v0.10 已替换为下述 CC0 模型，包含耳朵、眼睛、胡须、贴合身体的条纹、四肢和分节尾巴。`cat.route` 通过 `pathTo(target, origin, blockClosed)` 复用住宅寻路，不修改家长自身路线；模型与声音未增加下载、API 或依赖。橘猫独立于玩家衣柜。

## 听门轴、收力开合门（v0.14.2，日志 51）

靠近门按 E / □ 抓住门把。键鼠按住 E 或画面施力，松手马上停；PS5 轻压 R2 连续施力。开着的门可关上，R / L1 在特写中换开合方向。肩键不用于调速，也不显示速度数字、正确区间或进度条。

- 画面拉近原场景中的门，双手扶住门板和把手，门缝随真实角度张开；门轴发涩时有轻颤与连续咯吱声。声音字幕只描述正在发生的动作，不报正确速度。
- `source/door.js` 根据施力和门角度计算真实转速：慢速轻轻咯吱，中速经过涩点明显发响，高速滑动时声音减弱。按键以每秒 0.56 增加施力，R2 连续读取压深；角度涩点和原自适应扳机阻力保留。这里是游戏内旧门的调校，不代表所有现实门轴。
- 一直最大力气推到全开会猛撞限位门框，接触瞬间发出明显巨响、双手短促反冲和一次较强震动；关到底同样适用。按到头那一刻的真实转速判断，最后一小段减小 R2 压深，或键鼠松手后短推，可以轻停。之前大力不会使最后的轻推被误判为撞门。
- 撞击实录从主要瞬态前起播，强弱随接触力度变化；父母听闻仍受距离、其他遮挡和环境掩护影响，手里受力不被鼾声减弱。撞门字幕短暂优先于紧跟的父母翻身声；终点立即恢复移动，反冲只作用于手与合页，不回摆门扇碰撞体。
- 摩擦程度同时影响录音和安静推门评分；每 0.75 秒实际推门时间汇总噪声，从门位置影响父母。轻微摩擦与停顿不罚分，明显摩擦、撞击和环境掩护仍进入原声音规则。
- 门扇扫过角色时停住。父母先走出扫掠区，等待玩家完成／取消后再操作门，避免抢把手后自己挡住自己。正常巡查和视线识别保留，Esc / ○ 可退出挪开，R / L1 可反向。
- 取消、刷新和续玩保留已开的角度；物理施力不存档，恢复后重新按下才会动。兼容既有 v4 进度，原 `speed` / `doorBand` 已不参与计算。
- `source/door-detail.js` 提供真实门上的合页与扶门双手；连续录音由 `Soundscape.doorMotion` 接续并平滑调节，松手/暂停/失焦/断线后收声。开门时音乐降至常规混音的四分之一，动作音量继续遵守设置。

录音与处理记录见 [音频来源](assets/audio/README.md)。无新运行时依赖、外部请求或专用驱动；实体 DualSense 的压感手感仍需学生连接后体验。

## PS5 自适应扳机与震动（v0.14.1）

用 USB 连接 DualSense，在桌面 Chrome / Edge 打开游戏并按一下手柄。进入“夜间设置”，用鼠标点击“连接 DualSense（USB）”，在浏览器弹窗里选择设备，再试一下震动和 L2 / R2。震动与阻力有独立开关、强度调节和立即停止按钮；刷新后需再次点击连接。两轮成果已合并公开为 v0.13.0，并通过线上针对性验证；准确范围见 [项目状态](PROJECT_STATUS.md)。

- 门轴发涩：不均匀轻颤，R2 阻力随涩点变化，收力减轻、松手释放。
- 移动：普通走路、蹲行、走上松动木板及借掩护自动跨板都不震动，脚步声音和惊动父母的规则保留。仅手动按空格／× 完成落脚操作时给一次短反馈。
- 接物：花瓶接触较沉，双扳机托重并在归位时卸力；铁盒托底压盖，叉子袖口止响；每枝接到的铅笔只给轻短脉冲。
- 其他用途：挠痒的轻阻力、摸猫低缓呼噜、手机来电短震、静音轻点，以及丢球、翻抽屉和开锁反馈。

自适应扳机仅支持本版 USB 通路；普通震动按浏览器与设备支持回退。USB 输出采用轻重震动兼容模式，不等同 PS5 音频驱动高精度触觉。实体 DualSense / Edge 尚未实测；报文与模拟手柄测试不能证明真实阻力手感。详见 [连接、用途和来源](docs/controller-feedback.md)。

## 场景一致与归位（v0.14.3）
