# DualSense 触觉支持与验证范围

实现版本：v0.13.0。核对日期：2026-09-10。

## 如何启用

1. 用可传输数据的 USB 线连接 PS5 DualSense 或 DualSense Edge，使用桌面版 Chrome / Edge 打开游戏，在手柄上按一下按键。
2. 打开“夜间设置”，用鼠标点击“连接 DualSense（USB）”，在浏览器自己的设备选择框里选中这只手柄。网站不能代替玩家批准设备访问；手柄菜单的模拟点击不保证具有浏览器所需的用户激活。
3. 查看连接状态，使用“试一下震动”及“试一下 L2 / R2”。测试少于一秒，也可以立即停止。
4. 震动和扳机阻力有独立开关、独立强度。刷新后保留设置，但本版需要再次点击连接设备；不会自动弹出授权框。

普通震动通过浏览器 Gamepad 接口，能否使用取决于系统、浏览器与手柄。本版自适应扳机仅实现 USB；选择蓝牙设备会提示改接 USB，不会发送猜测的报文。没有加入本机代理、驱动安装、运行时 CDN 或后台服务。

## 动作如何对应触觉

| 动作 | 手柄震动 | 自适应扳机 |
| --- | --- | --- |
| 开关门 | 发涩时不规则轻颤，力度由摩擦和施力决定；收力后减轻 | R2 在真实门轴涩点增加阻力，停手释放 |
| 普通落脚 | 木地板圆润轻震、瓷砖短脆、地毯很弱；蹲步更轻 | 不增加走路阻力 |
| 松动木板 | 受力轻震、成功落脚轻响、踩响时稍强 | 保留原落脚按键与时机 |
| 接花瓶 | 接触瞬间较沉的短脉冲 | 左右托重随倾斜变化，缓放时逐渐卸力 |
| 接铁盒 | 接触短脉冲，未压住的盖子轻颤 | R2 托底较沉、L2 压盖较轻 |
| 接叉子 | 细颤随袖口包住逐渐停止 | 右手托住、左手止响各有轻阻力 |
| 拦铅笔 | 每实际拦下一枝一个很轻的短脉冲 | 不制造持续托重 |
| 挠痒 | 轻微手部反馈随刺激增加 | R2 轻阻力，松手释放 |
| 手机来电 / 静音 | 原有每次来电预兆给短震，静音成功轻点一下 | 不更改静音操作 |
| 摸猫 / 丢软球 / 翻抽屉 / 开锁 | 低缓呼噜、轻投、短摩擦与轻点 | 不强加无关阻力 |

这些反馈只表现已有动作。未新增判定、奖励、噪声或难度；没有用震动透视墙后的父母。接物触觉使用独立事件，最后一枝铅笔完成结算时也保留接触脉冲。

## 实现边界

- `source/dualsense.js` 只接受 Sony `054c` 的 `0ce6` / `0df2`，并检查 47 字节 USB 输出报告 `0x02` 的描述符。输出仅启用震动及 L2/R2 字段，不读写麦克风、扬声器音量、灯光、校准或固件。
- 扳机使用 `0x21` 十区阻力与 `0x05` 释放模式，阻力上限为协议八档中的第五档，再乘用户强度。具体触觉曲线为 AI 实施选择，未做真实力学标定。
- USB 连接时由同一个报文管理震动和扳机，避免与 Gamepad 震动输出争抢；不可用时普通震动回退到 Gamepad。这里是轻重震动兼容模式，不宣称提供 PS5 主机的音频驱动高精度触觉。
- 连续输出最多每秒 20 次，重复内容合并；短接触反馈优先于连续纹理。停止替换队列中尚未发送的效果，暂停、取消、失焦、关闭页面、切换输入和断线路径清理输出。动画停止而事件循环仍工作时，300 ms 看门计时器发送释放；浏览器进程崩溃或物理连接已失效后不能保证软件继续发送释放命令。
- 尚未连接实体 USB DualSense / Edge 验证阻力、震动或系统驱动兼容。自动测试检查协议字节与应用行为，不代替实体手感。多个相同手柄同时连接的关联未实测，建议此次试玩只连接一只。

## 核对来源

以下为浏览器文档、原作者示例与协议研究。实现依据公开报文结构自行编写，未把这些项目的代码库打包进游戏。

- [Chrome：WebHID API](https://developer.chrome.com/docs/capabilities/hid)：设备筛选、授权选择、报告发送与断线事件。
- [MDN：GamepadHapticActuator.playEffect](https://developer.mozilla.org/en-US/docs/Web/API/GamepadHapticActuator/playEffect)：普通震动参数；`trigger-rumble` 表示扳机振动，不等于 DualSense 阻力控制。
- [nondebug：DualSense Explorer 源码](https://github.com/nondebug/dualsense/blob/main/dualsense-explorer.html)：USB `0x02` / 47 字节报告、右扳机偏移 10、左扳机偏移 21。
- [Linux：hid-playstation 驱动](https://github.com/torvalds/linux/blob/master/drivers/hid/hid-playstation.c)：输出结构、震动及非触觉标志位分离。
- [Nielk1：Trigger effect factories](https://gist.github.com/Nielk1/6d54cc2c00d2201ccb8c2720ad7538db)：十区反馈的位掩码、三位力度打包及释放效果。
