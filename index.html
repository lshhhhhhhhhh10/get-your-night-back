01 / 一间熟悉的房子来自可玩版本的实际画面

01 — DESIGNER STATEMENT

轻一点，
还远远不够。

这个项目来自 Daniel 初中时的生活经验：晚上取回被家长藏起来的电子设备。看似只需要动作轻巧，实际上还要判断木地板是否会响、门轴适合怎样推、父母是否已经熟睡，以及突然有脚步时能躲到哪里。

游戏把这些判断转化成可尝试、可听见、可调整的行动。声音既是行动反馈，也是判断环境的依据：太响会留下风险，合适的背景声也能掩护行动。扩建后的住宅以附近小地图引导探索；家具按居住用途成组摆放，通道与模型对应。家长会走动、停看，听见明显声响后转去调查；蹲行、地板与门轴的不同声音，让路线选择有实际后果。

“我只要走得够轻”→“先看环境，再决定怎么走”

02 — THE SYSTEM

听见反馈，改变下一步。

观察→判断→行动→读取反馈→调整

环境提供条件

地板、门轴、光线、家具遮挡和设备候选藏点。相同动作在不同位置，可能发出不同的声音。

玩家作出选择

方向、落脚时机、开门速度、搜索与停下，以及贴近家具后蹲下躲藏。翻找时可能碰落叉子、笔筒或铁盒；慢动作特写中按 ×（手柄）或空格接住，失手会引起声响。

系统让后果可见

声响经过距离和墙体衰减，影响父母警觉。鼾声、床板声、脚步和暖光提示状态变化，并配有文字反馈。

学生原始系统图 · 点击查看大图。当前版本已按学生要求删除喝水量变量；未加入体力条。数值为可调整原型参数。

成功，是把设备带回来。

找到设备只是中途目标。回到自己的卧室安全区域，且尚未被识别，才完成这一夜。

一声吱呀，不会立刻结束。

声音会引起警觉和检查。只有父母在无遮挡的近距离视线里持续看见玩家约 0.25 秒，就会判定失败。

UP CLOSE / 近一点，慢慢找

镜头跟着你，也跟着好奇心。

肩后的夜探视角

V / 手柄 R3 切换第一人称与近景第三人称。鼠标或右摇杆转头，镜头避开墙壁与家具；M / △ 查看全景，再按一次返回刚才的近景。

抽屉里，书页间

翻找会拉近镜头、滑出抽屉，双手拨动物件或抽出书本。读题暂停，翻找仍在进行；听到脚步可按 Esc / ○ 停下。

换个圆滚滚的身影

衣柜加入奶龙、奶白色奶蛙与奶鼠的自制游戏改编外观。猫也换成 Quaternius 的圆润低多边形模型，并保留跟随、蹭腿和玩具互动。

LITTLE CLUES / 新的夜探选择

拼出线索，再听一听房子。

线索，比乱翻更有用

床头便条、茶几留言要先整理或解开小谜语，书架夹页需要实际翻找。按 E / □ 开始，解开后才记入 J / Create 线索本；收集证据再解开柜锁。

声音，也能帮你

趁长鼾声或附近洗衣机脱水时通过木板。也可以启动收音机、玩具鸭，趁延迟响起前离开，让家长去查看声源。

拿到手机，先别急

屏幕亮起，有人来电。停下按住 E / □ 1.2 秒静音，再找机会返程。来不及也能补救，但铃声会引来注意。

表现与意外

任务完成以后，看看这一夜怎样度过。

完成任务 · 40 分

找到设备，还要安全带回卧室。未完成时只记录练习表现。

声音与动作 · 50 分

声音控制、落脚时机、推门和接物各有依据。结算给出分项和原因，探索与等待不扣分。

避开视线 · 10 分

听清脚步，借家具遮挡。评分鼓励观察和调整，没有竞速倒计时。

松动地板与周围颜色一致，受力声才是提示。翻找餐边柜等家具时，可能发生与物件有关的意外；特写结束后恢复原视角与搜索进度。

03 — THREE DIFFERENT NIGHTS

同一间房子，三种判断。

01 / FIRST CREAK

第一声吱呀

穿过客厅，探索东侧书房和两个藏点与可翻找书架。整理睡前便条，再按书签顺序打开图案锁。

学习：落脚与门速
02 / WHICH WAY?

今晚走哪边

书房、餐厅、储物间和洗衣间，五个可能藏点。结合床头图案与茶几数字对照，解开收纳柜的三位密码。

学习：路线与搜索
03 / FOOTSTEPS

脚步近了

结合床头、茶几和书架三处信息，推导四位柜锁；父母仍会起夜巡视，翻找时随时听脚步停下。

学习：停下与应变

本版按学生试玩反馈扩大探索范围。时长取决于搜索、等待和重试，不设强制倒计时；人类游玩时长仍待测量。

THE HOUSE CAT / 家里的小跟班

你想悄悄走，它想蹭蹭你。

圆滚滚的橘猫会悄悄跟来，停下蹭腿；靠近花瓶时，又忍不住压低身子准备起跳。你可以绕开，也可以摸摸它，或者把玩具球丢向另一边。

摸一摸，先别闹

靠近 E / □ 安抚，听到呼噜声后，猫会安静坐一会儿。猫不会把你的路堵住。

球滚远了，猫也去了

Q / R2 丢出软球，让猫暂时离开你的路线。前方没有落点就换个方向，不需要管理物品栏。

盯住它的尾巴

起跳前有蓄势和提示，安抚、玩具或退开都能中断。真碰到了花瓶，还可以在慢动作里伸手接住。

WARDROBE / 九套夜间外观

今晚，换一身再出发。

主菜单新增皮肤衣柜：围巾夜行、螃蟹侦察员、偷吃小厨师、纸箱潜行员、抱枕骑士和晚安星星。选择后可旋转三维预览，确认“穿上这套”才会更换，并保存在当前浏览器。

九套全部可选，只影响玩家外观。纸箱不能让家长认错，抱枕也不会降低声音；移动、潜行与评分规则保持一致。支持鼠标拖动和 PS5 手柄选择、旋转及确认。

CONTROLS / DUALSENSE

插上手柄，轻轻走进夜晚。

PS5 手柄通过可传输数据的 USB 线连接电脑，在游戏页面按一下 × 识别。左摇杆移动，右摇杆转头；□ 交互，× 落脚或接住，○ 蹲行与取消，△ 切换全景，Options 暂停。推门时按住 □，L1 / R1 调节速度。

菜单可用方向键、× 和 ○ 操作；设置内可调手柄转头速度与摇杆死区。断开手柄会暂停，重新接入、松开按键后按 Options 继续。浏览器若尚未允许声音，点击页面的开启声音提示一次。
